# Ciencia de Datos e Inteligencia Artificial

Repositorio académico correspondiente a la **Tecnicatura Superior en Ciencia de Datos e Inteligencia Artificial**.

Este espacio tiene como finalidad organizar y documentar los trabajos prácticos, ejercicios, actividades y proyectos desarrollados durante la cursada, registrando los conocimientos adquiridos y su aplicación práctica.

## 📚 Contenidos

### 1. Introducción a Deepnote
- Primeros pasos en el entorno de desarrollo.
- Configuración del espacio de trabajo.
- Creación y ejecución de notebooks.

### 2. Python – Repaso
- Variables y tipos de datos.
- Operaciones matemáticas.
- Condicionales.
- Listas y estructuras de datos.
- Bucles e iteraciones.
- Resolución de ejercicios prácticos.

### 3. Bibliotecas de Python
- Introducción a bibliotecas.
- Importación y utilización de módulos.
- Aplicación de herramientas para programación y análisis de datos.

### 4. Entregas grupales
Espacio destinado a los trabajos prácticos y proyectos realizados en equipo durante la cursada.

## 🛠️ Tecnologías y herramientas

- **Python:** lenguaje de programación.
- **Deepnote:** entorno de desarrollo y ejecución de notebooks.
- **Jupyter Notebook:** desarrollo de ejercicios y documentación de código.
- **Git:** sistema de control de versiones.
- **GitHub:** almacenamiento y organización del repositorio.

## 🎯 Objetivos de aprendizaje

- Incorporar fundamentos de programación utilizando Python.
- Desarrollar habilidades para la resolución de problemas mediante código.
- Conocer herramientas y bibliotecas del ecosistema Python.
- Introducir conceptos relacionados con el análisis y procesamiento de datos.
- Comprender el funcionamiento de herramientas de control de versiones.
- Aplicar los conocimientos mediante actividades individuales y grupales.

## 📌 Actualizaciones

El repositorio se actualizará progresivamente con nuevos ejercicios, trabajos prácticos, materiales y proyectos correspondientes a las distintas materias de la tecnicatura.
